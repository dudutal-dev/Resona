# סאונדי סביבה

שכבת הסביבה של Resona **מסונתזת בזמן אמת** (גשם, ים, רוח, רעש לבן/ורוד/חום) ולכן
אינה דורשת קבצי אודיו כלל: אין לופ שנשמע חוזר, אין משקל הורדה, ואין שאלת רישוי.

אם בכל זאת רוצים להוסיף קבצים משלכם (למשל הקלטה אישית, או קובץ CC0 מ-Freesound):

1. שימו את הקובץ בתיקייה הזו — `public/audio/ambience/`.
2. הוסיפו רשומה ל-`manifest.json`:

```json
[
  { "id": "forest", "label": "יער", "file": "forest.mp3" }
]
```

3. הפעילו מחדש את השרת. הקובץ יופיע בבורר הסביבה במיקסר לצד האפשרויות המסונתזות,
   ינוגן בלופ עם fade in/out, וייכנס אוטומטית ל-cache של ה-Service Worker לשימוש אופליין.

פורמטים נתמכים: MP3, OGG, WAV, M4A.
